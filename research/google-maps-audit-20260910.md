# Google Maps評価・レビュー件数 再監査スナップショット（2026-09-10）

## 目的と位置づけ

この文書は、2026年9月23日〜28日の三陸旅行について、current primeと候補母集団にGoogle Mapsの外部シグナルを加えた再監査記録である。旅程をGoogle Maps順に並べ替えるものではなく、テーマ適合だけで高く評価していた候補を実訪問者の大量レビューで点検する。

個別値と機械可読な再評価は `catalog/places.yaml` と `catalog/food.yaml`、主要判断の根拠は `evidence/sources.yaml`、後続作業は `issues.yaml`、current primeへの影響は `plan/current.yaml` に保存した。本書は人が読む監査時点のスナップショットである。

## 判定ルール

- `rating` と `review_count` は必ずセットで見る。4.5・20件と4.2・2,000件を同じ信頼度にしない。
- ジャンル横断の一律閾値は使わない。星、件数、ジャンル、レビュー本文、施設の性質、ユーザー嗜好を組み合わせる。
- 博物館、資料館、科学館、観光展示施設は一般に高評価が出やすいため、十分なレビュー件数がある4.0未満を警戒シグナルとする。展示量、価格、対象年齢、古さ、期待値との差、内容の薄さを本文まで確認する。
- ラーメン、町中華、古い食堂、地方スーパーは評価が厳しく出ることがある。3点台後半でも星だけで落とさず、看板料理、地域性、レビュー本文、店の個性を見る。
- 市場・商業・観光の複合施設は全体評価を内部施設へ転用しない。
- Google Mapsだけで候補を削除せず、Google Mapsを無視もしない。一般客とユーザー嗜好の差を明示する。
- 確定できなかった値は推測せず `null`、`verification_status: needs_recheck` とする。

今回の `acquisition_confidence: medium` は、対象名・地域が一致するものとしてユーザーから共有された再監査結果だが、Google Mapsの直接URLがなく、レビュー件数が概数であることを表す。値が確認できなかった対象は `unknown` とした。
