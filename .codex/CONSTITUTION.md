# Codex 憲法

## ChatGPT への調査依頼プロンプト

- ChatGPT への調査依頼プロンプトは、ユーザーがそのまま ChatGPT にペーストできる本文だけで構成する。作成者向けの説明、貼り付け方の案内、ファイルパスだけを示すメタ情報、前置きは含めない。たとえば「このプロンプトを ChatGPT に貼り付けてください」は含めない。
- ChatGPT に調査を依頼するために作成する一時プロンプト、自己完結した引き渡し資料、添付用アーカイブは、`.codex/local/chatgpt-research/` にのみ置く。この領域は Git 非追跡とする。
- 調査依頼の目的を果たした時点（ChatGPT の回答を受領した、依頼を取りやめた、または依頼内容を置き換えた時点）で、当該依頼のプロンプト・引き渡し資料・アーカイブをガベージコレクションする。
- ガベージコレクションは、対象の依頼単位のファイルを削除することを指す。回答からリポジトリへ反映した恒久的なデータや、再現性のために追跡すべき成果物は削除対象に含めない。
- 削除前に、対象が `.codex/local/chatgpt-research/` 配下であることを確認する。未完了の依頼、他の依頼で参照中の資料、またはユーザーが保存を明示した資料は削除しない。
- 依頼が完了したことを報告する際は、ガベージコレクションした対象があれば、その旨を簡潔に併記する。
